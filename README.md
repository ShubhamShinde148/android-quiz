📱 Android App Development Quiz

LINK 🔗 https://androidcia2.netlify.app/

A modern, responsive web-based quiz application designed to test and strengthen your knowledge of Android app development.

Built using HTML, Bootstrap 5, and JavaScript, this project delivers a smooth, interactive quiz experience directly in the browser — no backend required.

🚀 Features

✨ Comprehensive Question Set

80 carefully curated questions
Covers Android fundamentals, UI/UX, components, lifecycle, and best practices

📄 Smart Pagination

20 questions per page
Smooth navigation with Previous / Next controls

📊 Instant Result Evaluation

Real-time score calculation
Detailed feedback and answer review

🎨 Multiple Themes

🌙 Dark Mode (Default)
☀️ Light Mode
💻 Hacker Mode (for that cyber vibe 😎)

📱 Fully Responsive Design

Works perfectly on mobile, tablet, and desktop

🧩 Modern UI

Built with Bootstrap 5
Clean layout with Google Fonts
App-like experience (one question per screen option)

⚡ No Backend Needed

Runs entirely in the browser
Lightweight and fast

🛠️ Getting Started
📌 Prerequisites
Any modern browser:
Chrome
Firefox
Edge
Safari
(Optional) Node.js for local server
▶️ Run Locally
1️⃣ Clone the repository
git clone https://github.com/your-username/android-quiz.git
cd android-quiz
2️⃣ Start a local server (Recommended)
npx serve
3️⃣ Open in browser
http://localhost:3000/ANDROID%20QUIZ/INDEX.HTML
⚡ Alternative (Quick Run)

Just open directly:

ANDROID QUIZ/INDEX.HTML
